## Cài đặt
- **Mac**: mở file .dmg, kéo app vào Applications. Lần đầu: Cài đặt hệ thống → Quyền riêng tư & Bảo mật → *Vẫn mở*.
- **Windows**: giải nén, bấm đúp `DownloadDriverAI.exe` (nếu Windows cảnh báo: *Thông tin thêm → Vẫn chạy*).
